# Images

`YYYY-MM-DD_provider_description.jpg`, filed under `xray/`, `dental/`, `clinical/` or
`passport/`. Register each one in the `images:` list in `data/gatsby_data.yaml` so it
appears in the gallery and can be attached to timeline events.

**One thing to be aware of:** the radiographs from Andreaspark carry a burnt-in overlay
with Gatsby's name, date of birth, microchip number and the clinic's name and address.
No owner details, but the chip number is visible. If you would rather it were not public,
crop the top strip before committing.
